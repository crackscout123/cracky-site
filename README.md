# cracky-site

Kleine Landingpage für **cracky.dev** auf Basis von Vite, JavaScript und Tailwind CSS.

Die Seite dient aktuell als ruhiger Platzhalter für eine spätere Hosting-Marke und bringt bereits Light-/Dark-Mode, eine klare Landingpage-Struktur sowie erste CTA- und Service-Bereiche mit.

## Stack

- Vite
- Vanilla JavaScript
- Tailwind CSS v4

## Entwicklung

Repository klonen und Abhängigkeiten installieren:

```bash
npm install
```

Dev-Server starten:

```bash
npm run dev
```

Build erzeugen:

```bash
npm run build
```

Build lokal prüfen:

```bash
npm run preview
```

## Projektstruktur

```text
src/
├── main.js
└── style.css
```

## Status

Aktuell ist das Projekt bewusst schlank gehalten und dient als Basis für weitere Schritte wie:

- Text-/Copy-Feinschliff
- zusätzliche Branding-Elemente
- Kontaktbereich oder Kundenbereich
- Deployment auf GitHub Pages oder eigenes Hosting

## Hinweis

Das Projekt ist als statische Frontend-Seite aufgebaut und kann daher sehr einfach lokal entwickelt und später auf nahezu jedem Webserver oder Static-Hosting-Dienst ausgeliefert werden.
